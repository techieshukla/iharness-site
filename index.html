iHarness

Self-hosted, local-first AI coding agents. Your code, credentials, and conversations stay on devices you control.

What is iHarness?

iHarness is an open-source gateway and client for running AI coding agents on your own machines. It connects your editor, browser, and mobile devices to agents running locally or on your private network.

  • Self-hosted gateway runs on macOS, Linux, Windows, or Docker.
  • Web, PWA, desktop, and Android clients.
  • Push notifications for agent activity.
  • No cloud account required; your data stays local.

Open source

iHarness is a fork of giuliastro/harness-remote. Source code and setup instructions are available on GitHub.
